# 🤖 Daily Motivation Message Bot

An AI-powered automation bot that generates positive and motivational messages using **Google Gemini AI** and automatically sends them to users through **Telegram** on a scheduled basis.

This project is built using **n8n workflow automation**, combining AI and messaging services to create an automated daily motivation system.

## 🚀 Features

- 🤖 AI-generated motivational messages
- ⏰ Scheduled automatic message delivery
- 💬 Telegram integration
- 🧠 Google Gemini AI integration
- ⚡ Fully automated n8n workflow
- 🌱 Helps provide daily positive motivation
- 🔄 Reduces manual effort

## 🛠️ Technologies Used

- **n8n** – Workflow automation
- **Google Gemini AI** – Generates motivational content
- **Telegram Bot** – Sends messages
- **AI Agent** – Processes and generates responses
- **Schedule Trigger** – Automates daily execution

## ⚙️ Workflow

The automation works in the following steps:

1. ⏰ **Schedule Trigger**
   - Starts the workflow automatically at the scheduled time.

2. 🤖 **AI Agent**
   - Receives the workflow request.
   - Uses AI to generate a meaningful motivational message.

3. 🧠 **Google Gemini Chat Model**
   - Provides AI capabilities to generate unique and positive content.

4. 📱 **Telegram**
   - Sends the generated motivational message to the user.

## 🎯 Project Objective

The main goal of this project is to demonstrate how **AI and workflow automation** can be combined to create a useful productivity and motivation tool.

Instead of manually creating motivational messages every day, the bot automatically generates and delivers them through Telegram.
